# Migrate file storage to Cloudflare R2 + hosting to Northflank

Scope (confirmed): Supabase keeps Postgres + Auth. R2 replaces Supabase Storage. No data migration — start fresh. Supabase Storage calls stop being used; Supabase JS stays installed for DB/auth.

## Design
One R2 bucket with key prefixes mirroring today's buckets: `source-videos/`, `clips/`, `assets/`, `user-uploads/`. DB keeps storing paths exactly as today (and the `storage:user-uploads/<path>` pseudo-scheme stays). Only the storage layer swaps: signed URLs → R2 presigned GETs, uploads → S3 PutObject or browser PUTs to presigned URLs. Public things (thumbnails, branding logo, feedback attachments) get a public base URL via R2 public access (`R2_PUBLIC_BASE_URL` env).

## Code changes
1. **New storage lib** — `backend/src/lib/r2.js` and `worker/src/lib/r2.js` using `@aws-sdk/client-s3` + `@aws-sdk/s3-request-presigner` (add to both package.json). API: `upload(key, body, contentType)`, `download(key)`, `remove(keys)`, `presignGet(key, expiresIn)`, `presignPut(key, contentType, expiresIn)`, `publicUrl(key)`. New env vars: `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`, `R2_PUBLIC_BASE_URL` (add to backend/src/config/env.js, worker/src/lib/env.js, and both .env.example files).
2. **Backend routes** — replace `supabaseAdmin.storage` in `routes/clips.js` (signed URLs → presigned GET), `routes/projects.js` (removes), `routes/admin.js` (logo upload + public URL + removes).
3. **Worker pipelines** — `lib/source.js` (downloads), `pipelines/download.js`, `render.js` (uploads + 7-day presigned URLs for Shotstack), `finalize.js` (upload + raw-clip remove), `publish/index.js` (7-day presigned for social APIs).
4. **Frontend** — new backend endpoint `POST /api/uploads/presign` (auth'd, takes key + contentType, validates `{userId}/` prefix, returns presigned PUT). Then:
   - `app/dashboard/new/page.tsx` (video upload incl. chunked manifest parts) and `app/dashboard/projects/[id]/clips/[clipId]/page.tsx` (b-roll/music uploads) → fetch presigned PUT, browser PUTs directly to R2.
   - `components/dashboard/clip-card.tsx` preview/download → use the existing backend signed-URL endpoints instead of direct supabase calls; thumbnail `<img>` → `R2_PUBLIC_BASE_URL`-based URL (backend returns it in clip payload).
   - `app/admin/page.tsx` + `app/dashboard/feedback/page.tsx` public URLs → public base URL (backend-returned).
5. **Frontend Dockerfile** — worker/backend already have Dockerfiles; add one for frontend so Northflank can build all three services.

## What you (user) need to do afterward
- Cloudflare: create the R2 bucket, enable public access (r2.dev or custom domain) for thumbnails, create an S3-compatible API token; put its values into env vars.
- Northflank: create project + 3 services from the repo (backend, worker, frontend) + Redis addon; set all env vars (same names as Railway plus the new R2_* ones); note the public URL of the backend.
- External redirects: update Meta/TikTok/YouTube OAuth redirect URIs, the Shotstack webhook URL, and Supabase Auth redirect list to the new Northflank domains.
- I'll give you a concise checklist with exact env var names at the end.
